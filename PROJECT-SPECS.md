> Portfolio status policy: the projects in this catalogue are presented as demo work, replicas, concepts or systems under development. They are not represented as finished client deployments unless explicitly stated.

## Shared development baseline
- Responsive, production-oriented UI system.
- Accessible keyboard navigation and semantic controls.
- Authentication and role-based permissions for business applications.
- API layer with validation and structured errors.
- Database schema, migrations and seed/demo data.
- Audit logging for important actions.
- Search, filtering, pagination and export where appropriate.
- Notification and task patterns.
- Docker-ready deployment structure.
- Environment-based configuration.
- Testing-ready architecture.
- AI modules remain provider-agnostic where possible.
