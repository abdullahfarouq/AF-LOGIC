# AF-029 — InvoiceVision

**Category:** AI & Automation  
**Status:** Demo / In Development  
**Description:** AI invoice extraction and validation

## Features
- Invoice OCR
- Vendor detection
- Line-item extraction
- Duplicate checks
- Approval queue
- Accounting export

## Development direction
Build a polished demo that demonstrates the business workflow, realistic seed data, responsive UI, role-aware actions, auditability and a clear path to a production architecture.

## Suggested delivery layers
1. UX and information architecture
2. Database and API
3. Core workflow
4. Dashboard and reporting
5. Permissions and audit
6. Automation / AI expansion where applicable
7. QA, performance and deployment

## Portfolio positioning
This project is presented honestly as a demo, replica, concept or work in development. It should not be described as a completed client deployment unless that becomes true.
